# 勉強ノート

iPad と Apple Pencil のための手書きノートアプリ（PWA）。
GitHub Pages に置いて Safari で開き、「ホーム画面に追加」するとアプリとして全画面で使えます。
インストール不要・サーバー不要・オフラインでも動きます。

## できること

- **低遅延の手書き**：筆圧対応（万年筆／ボールペン／筆ペン）、240Hz 入力の取りこぼし防止、ペン先の予測描画
- **きれいな線**：1 本の線を縁が重ならない 1 つのなめらかな輪郭として描く（点が連なったような見た目にならない）。筆圧の細かな揺れは平滑化
- **高画質**：画面に見えている部分を、いつでも表示倍率ちょうどの解像度で描く。ズームアウトしても画質を落とさず、最大ズームでも線や罫線がぼやけない・モザイクにならない。
  強く拡大したときは線を滑らかに補間するので、カーブがカクカクしない。書き終えた線は書いている時と同じ形で確定するので、ペンを離しても線がにじまない
- **ぐしゃぐしゃ消し**：ペンを離さず一筆で何度も往復すると、触れた線がまるごと崩れるように消える
  （ジグザグでもぐるぐるでも反応。判定はその一筆だけで行い、「あ」のように線が交差する普通の字では反応しません。間違えて消えたときは「元に戻す」で戻せます。感度は 1〜10 のスライダーで調整）
- **ズーム**：素早く動かしている最中でも 2 本指ですぐズームできる。感度（指の開閉に対する拡大・縮小の大きさ）は 1〜10 で調整。指がツールバーの上に乗っていても、ペンを持ったままでも反応する。
  指が止まる・離れた瞬間に表示倍率ちょうどの画質で描き直す
- **移動**：移動の感度・指を離したあとの滑り・ページのめくりやすさを、それぞれ 1〜10 で調整
- **図形補正**：直線・弧・曲線・折れ線・円・四角・三角・多角形を描いてペンを止めると整う。離さずに動かすと大きさ・向きを調整。
  はっきりした角の数で形を決めるので、角が丸くなっても三角形・四角形として認識。少しいびつな円は正円に、曲線は手ぶれをならしてなめらかに
- **吸着**：長押しで整えた図形や図形ツールの端・角は、近くにある図形の角・端点・円の中心、または辺・円周に吸い付く（吸い付いた所に丸印。手書きの文字には吸い付かない）
- **図形ツール**：直線・矢印・四角・角丸・円・三角・ひし形・多角形・星など 12 種類（塗り・縦横比固定）
- **スタンプ**：なげなわで選んだものを保存して、スタンプツールでタップするだけで貼れる
- **蛍光ペン**（下の文字を透かす）、**消しゴム**（部分消し／線ごと）、**なげなわ**（移動・拡大縮小・回転・色変更・コピー・別ページへ移動）
- **テキスト**、**画像の貼り付け**（写真・スクリーンショット）
- **ページ**：横に並ぶページを左右にスワイプ。拡大中は勢いで隣のページへ行かず端で止まる（端からさらに大きく引っ張ると移動）。
  縦スクロールが斜めになってもページはめくれない。最後のページでさらに引っ張ると同じ形式のページを追加。
  無地・横罫・ドット罫・方眼・ドット・コーネル・五線譜（**罫線・方眼・ドットの間隔は 2〜15mm で自由に**）、紙の色 6 色、A4／B5／正方形／16:9、**画像からページ**（縦横比を自動で合わせる）
- **ズーム**：いちばん縮小するとページ全体＋まわりに少し余白（設定で変更可）。指を離すとページが見やすい位置に自動で戻る
- **整理**：フォルダ（入れ子OK・色分け）、長押しでドラッグして移動、複数選択、お気に入り、検索、並べ替え、ゴミ箱（30 日）
- **ジェスチャー**：2 本指タップで元に戻す／3 本指でやり直し、ピンチでズーム、ダブルタップで拡大
- **書き出し**：PNG・PDF・バックアップファイル（全ノートを 1 ファイルに）
- ツールバーは上下左右どこにでも移動可、ライト／ダークテーマ、アクセントカラー変更

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成（例：`benkyo-note`、**Public**）
2. このフォルダの中身（`index.html` や `js/` フォルダなど）をリポジトリのいちばん上にアップロード
   - ブラウザなら「Add file → Upload files」にフォルダの中身をまとめてドラッグ＆ドロップ
3. リポジトリの **Settings → Pages** で
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
4. 1〜2 分待つと `https://ユーザー名.github.io/benkyo-note/` が表示されます

## iPad に入れる

1. 上の URL を **Safari** で開く
2. 共有ボタン →「**ホーム画面に追加**」
3. ホーム画面のアイコンから起動（全画面のアプリとして動きます）

## アプリを更新したいとき

ファイルを書き換えて GitHub にアップロードしたら、**`sw.js` の `VERSION` の数字を上げてください**（例：`v1.0.0` → `v1.0.1`）。
iPad でアプリを開くと「新しいバージョンがあります → 更新」が表示されます。

## データについて（大事）

- ノートは **iPad の中（このアプリ専用の保存領域）だけ** に保存されます。GitHub には上がりません。
- そのぶん iPad を初期化したり、アプリ（ホーム画面のアイコン）を削除するとノートも消えます。
  **設定 → バックアップを書き出す** で定期的にファイルへ保存しておくと安心です（ファイル App や iCloud Drive に保存可）。
- 別の端末へ移すときも、バックアップファイルを「設定 → バックアップから復元」で読み込めます。
- Safari で開いたページと、ホーム画面に追加したアプリは保存領域が別です。普段はホーム画面のアプリから使ってください。

## ファイル構成

```
index.html            エントリ
manifest.webmanifest  PWA 設定
sw.js                 オフライン用 Service Worker
css/app.css           デザイン
icons/                アプリアイコン
js/
  app.js       画面遷移・テーマ・更新
  library.js   ノート一覧・フォルダ・ドラッグ整理
  editor.js    エディタ画面（ツールバー・ページ一覧・書き出し）
  engine.js    キャンバスエンジン（入力・描画・ズーム・選択・取り消し）
  ink.js       手書きストロークの形状計算・当たり判定
  scribble.js  ぐしゃぐしゃ消しの判定
  shapes.js    図形認識
  render.js    ページ描画（罫線テンプレート・テキスト・画像）
  store.js / db.js  データ保存（IndexedDB）
  exporter.js  PNG / PDF / バックアップ
  ui.js, pickers.js, panels.js, icons.js, settings.js, util.js
```

ビルド不要の素の JavaScript（ES Modules）です。
